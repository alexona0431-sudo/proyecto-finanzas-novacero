# Evidencias del proceso agéntico

Esta carpeta documenta el uso de inteligencia artificial en el proyecto de análisis económico, financiero y de ingeniería económica de Novacero S.A.

## Herramientas utilizadas

- Visual Studio Code como entorno de desarrollo.
- Agente de codificación integrado en Visual Studio Code.
- ChatGPT como apoyo para planificación, revisión, explicación y validación humana.
- Python para extracción, procesamiento, cálculos y auditoría.
- Next.js para el dashboard.
- GitHub para control de versiones.
- Vercel para el despliegue público.

## Contenido

- `registro_uso_ia.md`: tareas asignadas, respuestas aceptadas, corregidas y rechazadas.
- `decisiones_y_reflexion.md`: decisiones tomadas por el estudiante y limitaciones de la IA.
- Capturas de pantalla del proceso de trabajo.

## Criterio de validación

Ningún resultado generado por IA se aceptó únicamente por su redacción. Los datos financieros fueron contrastados con los PDF originales, los cálculos se ejecutaron mediante código reproducible y las igualdades contables fueron verificadas antes de utilizarse en el dashboard.
