# Prompts principales del proyecto

## Prompt general
"Analiza el caso de viabilidad económica y financiera de implementar un sistema fotovoltaico en la planta industrial de Novacero S.A. en Lasso, mediante financiamiento bancario. Actúa como un ejercicio académico, no como una inversión oficialmente anunciada. Usa solo fuentes verificables y documenta todos los supuestos."

## Prompt para el investigador económico
"Recopila contexto sectorial, regulatorio y de mercado relevante para el caso. Identifica fuentes verificables y resume su utilidad para el análisis."

## Prompt para el analista de datos
"Organiza la información disponible en una estructura de datos clara, define variables y prepara tablas limpias y trazables."

## Prompt para el analista financiero
"Revisa los supuestos financieros, costos, ingresos y estructura de financiamiento de la propuesta. Señala limitaciones y escenarios sensibles."

## Prompt para el ingeniero económico
"Traduce la propuesta técnica en escenarios comparables y define criterios de evaluación económica y financiera."

## Prompt para el valorador
"Sintetiza los resultados parciales y emite una valoración de viabilidad con base en la evidencia disponible y las limitaciones del estudio."

## Prompt para el auditor de riesgos
"Identifica riesgos, sensibilidades y limitaciones del análisis y documenta cómo podrían afectar la conclusión."

## Prompt para el visualizador
"Propón una estructura visual y narrativa para comunicar los hallazgos sin inventar datos ni exceder la evidencia disponible."
