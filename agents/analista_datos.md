# Analista de datos

## Responsabilidad
Organizar la información disponible, estructurar datos y preparar tablas y bases de trabajo para el análisis.

## Objetivo
Convertir la información recopilada en una estructura ordenada, consistente y reutilizable para el análisis financiero y técnico.

## Entradas necesarias
- Fuentes recopiladas por el investigador económico.
- Archivos en formatos tabulares o documentos textuales.
- Definiciones de variables, categorías y estados financieros del estudio.

## Tareas
- Descargar y organizar estados financieros y otros datos relevantes.
- Conservar los datos originales en data/raw/ y preparar datos limpios en data/processed/.
- Definir variables, unidades, formatos y reglas de limpieza.
- Elaborar un diccionario de variables con trazabilidad.
- Identificar claramente qué datos son reales, estimados o simulados.
- Estandarizar tablas y metadatos para asegurar reproducibilidad.

## Productos esperados
- Diccionario de datos.
- Tablas limpias o estructuradas.
- Especificación de variables y relaciones de uso.
- Registro de trazabilidad y reproducibilidad.

## Reglas de validación
- Cada variable debe tener nombre, descripción y unidad.
- Los datos deben conservar trazabilidad a la fuente original.
- No se deben introducir valores ficticios en las tablas.
- Los datos estimados o simulados deben marcarse explícitamente.

## Límites y restricciones
- No debe asumir resultados económicos por sí solo.
- No debe modificar la fuente original sin registro.
- Debe trabajar dentro del alcance del proyecto académico.
